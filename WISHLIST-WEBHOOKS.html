Wishlist webhooks

Use this if you want Salty HUB to notify your app when a customer wishlist changes.

You send us a topic and your HTTPS address. We POST JSON to that address.

Base URL: https://personalize.salty.co.in

WhatURL
Create webhookPOST /api/wishlist-webhooks
List webhooksGET /api/wishlist-webhooks
Delete webhookDELETE /api/wishlist-webhooks

2. Topics

Register one webhook per topic. Same address can be used for all five.

topicWhen we call you
wishlist/createdNew wishlist is created
wishlist/updatedFull list is replaced
wishlist/clearedWishlist is deleted
wishlist/item-addedProduct is added
wishlist/item-removedProduct is removed

3. Register

POST https://personalize.salty.co.in/api/wishlist-webhooks

Send JSON. address must be https://.

request 
curl -X POST https://personalize.salty.co.in/api/wishlist-webhooks \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "wishlist/item-added",
    "address": "https://your-app.com/webhooks/wishlist"
  }'
response 201 
{

}

4. Save the secret

webhook.secret is shown only when you create the webhook. Put it in your app env. Do not commit it. We never send it again on list.

If you lose it, delete the webhook and register again.

6. Verify (required)

This proves the POST came from us, not a random caller.

  1. Read the request body as a raw string (do not JSON.parse first).
  2. Read header X-Wishlist-Hmac-Sha256.
  3. HMAC-SHA256 the raw body with your secret.
  4. Encode that HMAC as Base64.
  5. If it matches the header, process the event. If not, return 401.
Node / Express 
import crypto from "node:crypto";
import express from "express";

const app = express();
const SECRET = process.env.WISHLIST_WEBHOOK_SECRET;

function isValid(rawBody, hmacHeader) {
  const digest = crypto
    .createHmac("sha256", SECRET)
    .update(rawBody, "utf8")
    .digest("base64");
  const a = Buffer.from(digest);
  const b = Buffer.from(String(hmacHeader || ""));
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}

app.post(
  "/webhooks/wishlist",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const rawBody = req.body.toString("utf8");
    if (!isValid(rawBody, req.get("X-Wishlist-Hmac-Sha256"))) {
      return res.status(401).send("Invalid HMAC");
    }

    const payload = JSON.parse(rawBody);

    if (payload.topic === "wishlist/item-added") {
      // payload.data.customer.email
      // payload.data.added[0].title
      // payload.data.added[0].price
      // payload.data.products
    }

    res.status(200).send("ok");
  },
);

app.listen(3000);

Use express.raw on this route. If Express parses JSON first, HMAC will fail.

7. Payload per topic

Every topic has data.shop, data.customer, and data.products. handles is also sent for convenience.

Each product object has: id, gid, title, handle, vendor, productType, status, tags, url, image, price, currency.

Each customer object has: id, gid, firstName, lastName, name, email, phone.

wishlist/created and wishlist/updated — full current list in products.

data keys 
{
  "shop": { "name": "Salty", "domain": "salty.co.in", "url": "https://salty.co.in", "myshopifyDomain": "store.myshopify.com" },
  "customer": { "id": "1234567890", "name": "Riya Shah", "email": "riya@example.com", "phone": "+919999999999" },
  "customerId": "1234567890",
  "handles": ["serum-handle"],
  "products": [{ "title": "Vitamin C Serum", "handle": "serum-handle", "price": "899.00", "currency": "INR", "url": "https://salty.co.in/products/serum-handle", "image": { "url": "https://cdn.shopify.com/..." } }]
}

wishlist/cleared — customer stays, products is empty.

data 
{
  "customer": { "id": "1234567890", "name": "Riya Shah", "email": "riya@example.com" },
  "handles": [],
  "products": []
}

wishlist/item-added — products is the full list. added is only the new products (full objects). addedHandles is the handle list.

wishlist/item-removed — products is what remains. removed is the products that were taken off (full objects if still in Shopify).

8. List and delete

List (secret is not returned):

list 
curl https://personalize.salty.co.in/api/wishlist-webhooks
curl https://personalize.salty.co.in/api/wishlist-webhooks?topic=wishlist/item-added

Delete by id, or by topic + address:

delete 
curl -X DELETE "https://personalize.salty.co.in/api/wishlist-webhooks?id=WEBHOOK_ID"

curl -X DELETE https://personalize.salty.co.in/api/wishlist-webhooks \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "wishlist/item-added",
    "address": "https://your-app.com/webhooks/wishlist"
  }'

9. Errors

StatusMeaning
400Bad topic, or address is not https
201Webhook created. Save secret
200Already registered, or list/delete ok. No new secret
401 on your sideHMAC did not match. Check raw body + secret

Checklist:

  1. HTTPS endpoint is live and returns 200
  2. You registered the topic you care about
  3. You stored webhook.secret
  4. You verify HMAC on the raw body
