Create a wishlist webhook

Same idea as Shopify: the developer sends a topic and an address. When that wishlist event happens, we POST JSON to that address.

Admin API: https://personalize.salty.co.in/api/wishlist-webhooks

  1. Pick a topic, for example wishlist/item-added
  2. POST your HTTPS endpoint as address
  3. Return 200 from that endpoint when we deliver the event

Topics

topicWhen it fires
wishlist/createdA customer wishlist is created
wishlist/updatedThe full list is replaced
wishlist/clearedThe list is deleted
wishlist/item-addedOne or more product handles are added
wishlist/item-removedOne or more product handles are removed

Create a webhook

POST /api/wishlist-webhooks

Pass topic and address. address must be https:// (or http://localhost while testing).

request body 
{
  "topic": "wishlist/item-added",
  "address": "https://developer.example.com/webhooks/wishlist",
  "format": "json"
}

Shopify-style wrapper also works:

request body (webhook object) 
{
  "webhook": {
    "topic": "wishlist/item-added",
    "address": "https://developer.example.com/webhooks/wishlist",
    "format": "json"
  }
}

Response 201 if it was new, 200 if that topic + address already existed:

response 
{
  "ok": true,
  "created": true,
  "webhook": {
    "id": "68ca1b2e3f4a5b6c7d8e9f01",
    "topic": "wishlist/item-added",
    "address": "https://developer.example.com/webhooks/wishlist",
    "format": "json",
    "created_at": "2026-09-17T07:30:00.000Z"
  }
}

Register once per topic. If you need all events, create five webhooks (one address can be reused).

What we POST to your address

After a customer changes a wishlist, every webhook registered for that topic receives:

headers 
Content-Type: application/json
X-Wishlist-Topic: wishlist/item-added
X-Wishlist-Webhook-Id: 9b3c1e2a-4d55-4f10-9c2a-1f0e8d7c6b5a
X-Wishlist-Triggered-At: 2026-09-17T07:31:12.000Z
X-Wishlist-Hmac-Sha256: Base64HMAC
body 
{
  "topic": "wishlist/item-added",
  "event": "wishlist/item-added",
  "created_at": "2026-09-17T07:31:12.000Z",
  "data": {
    "customerId": "1234567890",
    "handles": ["serum-handle", "face-wash"],
    "added": ["face-wash"]
  }
}

Your endpoint should respond with 2xx. Other statuses are logged and not retried yet.

Verify HMAC

Use the app secret (WISHLIST_WEBHOOK_SECRET or SHOPIFY_API_SECRET). Hash the raw body string, then compare to X-Wishlist-Hmac-Sha256.

Node.js 
import crypto from "node:crypto";

function verifyWishlistWebhook(rawBody, hmacHeader, secret) {
  const digest = crypto
    .createHmac("sha256", secret)
    .update(rawBody, "utf8")
    .digest("base64");
  const a = Buffer.from(digest);
  const b = Buffer.from(String(hmacHeader || ""));
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}
