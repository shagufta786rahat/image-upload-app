Wishlist Webhooks API

Register an HTTPS endpoint for a topic. When a customer wishlist changes, Salty HUB sends a signed JSON POST to that address. The payload includes shop, customer, and product objects.

Base URL

https://personalize.salty.co.in

Content type: application/json. Register one subscription per topic. You can reuse the same address for all five topics.

Authentication

Create and list endpoints are open HTTPS APIs. Incoming deliveries are authenticated with HMAC.

  1. Create a webhook and save webhook.secret. It is returned only on create.
  2. On each delivery, hash the raw body with HMAC-SHA256 using that secret.
  3. Base64-encode the digest and compare it to X-Wishlist-Hmac-Sha256.

Do not parse JSON before computing the HMAC. If the body is modified, verification fails.

Create a webhook

POST
/api/wishlist-webhooks

Request body

FieldTypeRequiredDescription
topicstringYesOne of the five wishlist topics.
addressstringYesHTTPS URL that receives deliveries. http://localhost is allowed for local tests.
formatstringNoMust be json.

Response

201 when created. 200 if the same topic and address already exist (no new secret).

create webhook
curl -X POST https://personalize.salty.co.in/api/wishlist-webhooks \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "wishlist/item-added",
    "address": "https://your-app.com/webhooks/wishlist"
  }'
create webhook
const response = await fetch(
  "https://personalize.salty.co.in/api/wishlist-webhooks",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      topic: "wishlist/item-added",
      address: "https://your-app.com/webhooks/wishlist",
    }),
  },
);
const json = await response.json();
// json.webhook.secret — store this
console.log(json.webhook.id, json.webhook.secret);
create webhook
$ch = curl_init("https://personalize.salty.co.in/api/wishlist-webhooks");
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_HTTPHEADER => ["Content-Type: application/json"],
  CURLOPT_POSTFIELDS => json_encode([
    "topic" => "wishlist/item-added",
    "address" => "https://your-app.com/webhooks/wishlist",
  ]),
  CURLOPT_RETURNTRANSFER => true,
]);
$json = json_decode(curl_exec($ch), true);
// $json["webhook"]["secret"]

Verify a delivery

Your endpoint must read the raw body, verify HMAC, then parse JSON. Return 200 quickly.

Express receiver
import crypto from "node:crypto";
import express from "express";

const app = express();
const SECRET = process.env.WISHLIST_WEBHOOK_SECRET;

function isValid(rawBody, hmacHeader) {
  const digest = crypto
    .createHmac("sha256", SECRET)
    .update(rawBody, "utf8")
    .digest("base64");
  const a = Buffer.from(digest);
  const b = Buffer.from(String(hmacHeader || ""));
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}

app.post(
  "/webhooks/wishlist",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const rawBody = req.body.toString("utf8");
    if (!isValid(rawBody, req.get("X-Wishlist-Hmac-Sha256"))) {
      return res.status(401).send("Invalid HMAC");
    }
    const payload = JSON.parse(rawBody);
    if (payload.topic === "wishlist/item-added") {
      const product = payload.data.added[0];
      console.log(payload.data.customer.email, product.title, product.price);
    }
    res.status(200).send("ok");
  },
);

app.listen(3000);
PHP receiver
$secret = getenv("WISHLIST_WEBHOOK_SECRET");
$rawBody = file_get_contents("php://input");
$hmac = $_SERVER["HTTP_X_WISHLIST_HMAC_SHA256"] ?? "";
$digest = base64_encode(hash_hmac("sha256", $rawBody, $secret, true));

if (!hash_equals($digest, $hmac)) {
  http_response_code(401);
  echo "Invalid HMAC";
  exit;
}

$payload = json_decode($rawBody, true);
http_response_code(200);
echo "ok";

curl -X POST https://your-app.com/webhooks/wishlist \
  -H "Content-Type: application/json" \
